# 🏙️ botyaracities-ru

[🇬🇧 English](README.md) · 🇷🇺 **Русский**

> **Сетевая игра «Города России» по LAN — играй в классическую цепочку городов с другом по локальной сети.**

Два игрока по очереди называют российские города. Каждый следующий город должен начинаться на последнюю букву предыдущего. Пропустил 30-секундный таймер или повторил город — теряешь жизнь. Три жизни — и ты выбыл. Pygame-клиент + asyncio TCP-сервер + бонусный CLI-поисковик городов.

**⚠️ Linux / macOS / Windows. Использует сырые TCP-сокеты — рассчитано на LAN, не на публичный интернет.**

---

## ✨ Возможности

### 🎮 Основной геймплей
- **Классические правила цепочки** — называй город на последнюю букву предыдущего
- **Автопроверка** по встроенной базе из **~400 реальных российских городов** (от Абакана до Яхромы)
- **Запрещённые буквы** (`ь`, `ъ`, `ы`, `й`, `ё`) автоматически пропускаются — игра берёт предыдущую реальную букву
- **Без повторов** — названный город уходит с поля
- **Очки** = количество букв в названном городе (Питер = +6, Ялта = +4)

### 💖 Жизни и таймер
- **3 жизни на игрока** — теряешь одну на таймауте и играешь дальше
- **30 секунд на ход** первые 10 ходов, **15 секунд** после — игра становится жарче
- **Анимированная пульсирующая полоса таймера** — зелёный → жёлтый → красный по мере убывания
- **Кто первый потеряет все 3 жизни — проиграл**

### 🎨 Визуал и «сочность»
- **Анимированный фон-аврора** с дрейфующими туманностями
- **150 мерцающих звёзд**, плывущих через экран
- **Система частиц** — вспышки при принятии города, красный взрыв при отказе, конфетти при победе
- **Всплывающий текст** — очки, предупреждения, потеря жизней
- **Тряска экрана** при ошибках, таймаутах и критических событиях
- **Стеклянные панели** с внутренним блеском и свечением
- **Анимированный заголовок** с волновым движением каждой буквы
- **Большой анимированный индикатор следующей буквы**, который пульсирует и увеличивается
- **Индикатор набора текста соперником** в реальном времени

### 🧠 Умная логика сервера
- **Авто-релаксация**: если на нужную букву не осталось городов, сервер выбирает случайную доступную букву и предупреждает обоих игроков
- **Случайный первый игрок** в каждой партии
- **Честная валидация** — отклоняет невалидные города, повторы и неверные первые буквы с конкретными причинами
- **Корректное завершение игры** — чистая очистка ресурсов, без висящих сокетов
- **Обслуживает 2 игроков** — комната закрывается, когда оба подключились

### 🖥️ Бонус: CLI-поисковик городов
Отдельный `search.py` даёт **интерактивный fuzzy-поиск** по всей базе городов:
- Печатай — совпадения подсвечиваются красным
- Стрелки для навигации, Enter для вставки в буфер
- Построен на `prompt_toolkit` — поддержка мыши, скроллбар, кастомная тема
- Идеально для читерства… то есть, для «тренировки»

### 🌐 Сетевой протокол
- **Простой JSON + 4-байтовый префикс длины** поверх TCP (`protocol.py`)
- **Асинхронный сервер** (`asyncio`) с потоками-слушателями на игрока
- **Синхронный клиент** с отдельным потоком приёма
- **События набора текста в реальном времени**
- Сообщения: `join`, `wait`, `game_start`, `turn_start`, `timer_tick`, `typing`, `submit`, `city_accepted`, `city_rejected`, `timeout`, `game_over`, `disconnect`

## 🚀 Быстрый старт

### Требования

- **Python 3.10+** (использует union `str | None`)
- **pygame** (клиент)
- **prompt_toolkit** (CLI-поисковик, опционально)

### Установка

```bash
git clone https://github.com/dimasbotyara/botyaracities-ru.git
cd botyaracities-ru

python -m venv .venv
source .venv/bin/activate     # Linux/macOS
# .venv\Scripts\activate      # Windows

pip install pygame prompt_toolkit
```

### Запуск матча

**Терминал 1 — запуск сервера:**
```bash
python server.py
# или с кастомным портом:
python server.py 5555
```

**Терминалы 2 и 3 — два клиента:**
```bash
python client.py
```

В каждом клиенте:
1. Введи своё имя
2. Введи IP сервера (`localhost`, если на той же машине, иначе LAN-IP)
3. Укажи порт (по умолчанию `5555`)
4. Нажми **ПОДКЛЮЧИТЬСЯ**

Матч начнётся автоматически, когда оба игрока подключатся.

### Бонус: CLI-поиск

```bash
python search.py
```

Печатай для поиска. `↑`/`↓` — навигация, `Enter` — вставить, `Esc` — выход.

## 🧠 Как работает валидация городов

Каждый город проходит три проверки на сервере:

1. **Есть ли в базе?** — нормализованный поиск в `CITIES_SET`
2. **Уже использован?** — проверка по `used_cities`
3. **Начинается с нужной буквы?** — первая буква сравнивается с `required_letter`

Если прошёл → город добавляется в `used_cities`, его последняя валидная буква становится следующей, игрок получает `len(city)` очков.

Если на **следующую** букву **нет доступных городов**, сервер выбирает случайную доступную букву и предупреждает обоих игроков всплывающим сообщением. Умно, дружелюбно и не даёт игре встать в тупик.

## 🔧 Кастомизация

### Добавить города
Редактируй `cities_db.py` — просто дописывай в `RUSSIAN_CITIES`. Индексы `CITIES_SET` и `CITIES_BY_LETTER` перестраиваются автоматически при импорте.

### Изменить время хода
Редактируй `GameServer.get_turn_time()` в `server.py`:
```python
def get_turn_time(self):
    if self.turn_number < 10:
        return 30
    return 15
```

### Изменить стартовые жизни
В `server.py` поменяй `self.lives = [3, 3]`.

### Изменить цвета / тему
Все константы палитры — в начале `client.py` (`BG_DARK`, `ACCENT`, `GOLD` и т.д.). Меняй, перезапускай, готово.

### Добавить игроков
Сейчас жёстко зашито на 2. Смотри `listen(2)` в `server.py` и обработку `player_id` в клиенте — архитектура поддерживает N игроков с небольшими правками.

## 🐛 Решение проблем

**Не могу подключиться между двумя машинами**
- Убедись, что сервер слушает на `0.0.0.0` (по умолчанию так)
- Проверь файрвол — порт `5555` должен быть открыт на машине-сервере
- Используй **LAN-IP** сервера (например, `192.168.1.42`), а не `localhost`

**«Это не город из базы!» на реальном городе**
- В базе ~400 городов. Редкие могут отсутствовать — добавь их в `cities_db.py` и перезапусти сервер.

**Чёрное окно Pygame при запуске**
- Убедись, что `pygame` установлен в том же venv, из которого запускаешь клиент.
- На HiDPI-дисплеях может понадобиться `SDL_VIDEO_X11_SCALING=1 python client.py`.

**Поисковик падает при импорте**
- `pip install prompt_toolkit` — это отдельная опциональная зависимость.

**Таймер продолжает тикать при лагах**
- Сервер отправляет `timer_tick` каждые 300мс; клиент доверяет этим сообщениям, так что при лагах время будет заморожено. Серверный таймаут всё равно срабатывает корректно.
